# Lucker Party

LuckerParty is [s&box](https://sbox.game/) party game inspired by projects like [Are you a Lucker?](https://www.hiveworkshop.com/threads/are-you-a-lucker-2-04.316946/) (Warcraft 3) and [Fretta Minigames](https://maurits.tv/data/garrysmod/wiki/wiki.garrysmod.com/indexdd30.html) (Gmod).

The base pack will contain a collection of fun, quick games to play with your friends.
