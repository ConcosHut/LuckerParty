Alt-Tab no longer opens a menu in the multiplayer party or first-person sandbox. The party stays on its current screen and its clock keeps running. In the sandbox, local movement and mouse capture stop while the window is unfocused, then return when focus does; an explicitly opened Escape menu remains open.

The new [Home, Join, Lobby and in-party menu concepts](https://github.com/ConcosHut/LuckerParty/tree/master/docs/design/party-ui-concepts) are review mockups, not an implemented UI redesign. Existing party rules, scoring, launcher behavior and sandbox controls remain available.
